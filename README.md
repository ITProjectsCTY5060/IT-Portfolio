## Academic Projects

### Springhill Medical Center — Enterprise Network Deployment

**CTN Capstone Group Project | Fanshawe College**

Collaborated with a team of four to design and implement a simulated enterprise network for a multi-tenant medical facility.

**Project Highlights:**
- Implemented 18 VLANs for network segmentation.
- Configured OSPF and inter-VLAN routing.
- Implemented network redundancy and backup routing.
- Applied ACLs and switch security configurations.
- Configured Windows Server services and Group Policy.
